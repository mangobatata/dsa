## LeetCode 283 — Move Zeroes

Tenemos:

```text
nums = [0, 1, 0, 3, 12]
```

Debemos modificar el mismo array para obtener:

```text
[1, 3, 12, 0, 0]
```

Reglas:

```text
No crear otro array
Mantener el orden de los números
Modificar nums in-place
Espacio extra O(1)
```

Este problema también puede pensarse con:

```text
i → explorador
k → escritor
```
