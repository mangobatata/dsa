# Learning Roadmap — DSA

Este roadmap documenta la progresión pedagógica adoptada para el estudio de Estructuras de Datos y Algoritmos, priorizando el razonamiento profundo y el reconocimiento de patrones sobre la memorización.

---

## Fases de Aprendizaje

```text
ETAPA 1 — Razonamiento + Estructuras Básicas [ACTUAL]
│
├── Arrays (operaciones, índices, recorrido inverso)
├── Hash Map / Set (claves, valores, lookup O(1) promedio)
├── Stack (LIFO, control de pendientes, anulaciones)
├── Frequency Counter (conteo y balances)
├── Estado / Memoria mental del problema
├── Big O (Tiempo y Espacio desglosados)
└── Problemas introductorios (Easy / Medium fundacionales)
        ↓
ETAPA 2 — Estructuras desde Cero
│
├── Array dinámico (redimensionamiento, amortización)
├── Linked List (Singly, Doubly)
├── Stack y Queue construidos sobre Linked List / Array
├── Hash Map con resolución de colisiones (Chaining / Open Addressing)
└── Pruebas unitarias de las implementaciones propias
        ↓
ETAPA 3 — Patrones Algorítmicos
│
├── Two Pointers (convergentes, ordenados, exclusión lógica) [EN CURSO]
├── Sliding Window (tamaño fijo y dinámico)
├── Prefix Sum
├── Binary Search (en arrays y sobre el espacio de respuestas)
├── Recursión y Backtracking
└── Divide & Conquer
        ↓
ETAPA 4 — Estructuras No Lineales
│
├── Trees y Binary Search Trees (BST)
├── Heap / Priority Queue
├── Trie (Prefix Tree)
└── Graphs (matrices y listas de adyacencia)
        ↓
ETAPA 5 — Algoritmos Avanzados
│
├── Breadth-First Search (BFS)
├── Depth-First Search (DFS)
├── Algoritmos de ordenamiento (MergeSort, QuickSort)
├── Topological Sort
├── Caminos mínimos (Dijkstra)
└── Greedy (Estrategias voraces)
        ↓
ETAPA 6 — Programación Dinámica (DP)
│
├── Subproblemas superpuestos y subestructura óptima
├── Memoization (Top-Down)
└── Tabulation (Bottom-Up)
```
