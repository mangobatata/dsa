# DSA

Repositorio personal de estudio y mentoría.

Este repositorio documenta una ruta progresiva de aprendizaje enfocada en:

* Data Structures & Algorithms.
* Resolución de problemas.
* Complejidad temporal y espacial.
* TypeScript.
* Python.
* PHP.
* Fundamentos de Internet y Web.
* Fundamentos de CyberSecurity.

La prioridad de este repositorio no es guardar únicamente soluciones finales.

La prioridad es conservar el proceso:

```text
problema -> intento -> razonamiento -> error -> descubrimiento -> patrón -> solución -> análisis
```

## Convención educativa

Cada ejercicio debe conservar el razonamiento original del estudiante.

Cuando una solución tenga errores, dudas o implementaciones imperfectas, deben quedar como parte del aprendizaje. Las observaciones pueden documentarse aparte, sin reemplazar silenciosamente el trabajo original.
